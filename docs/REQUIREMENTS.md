# 当前功能要求

本文件记录可验收行为。具体 API 字段由模型和自动生成的 [API 参考](API_REFERENCE.md)定义；实现分层见[设计](DESIGN.md)。

| 编号 | 范围 | 验收要求 |
| --- | --- | --- |
| R01 | 本地启动 | 单 worker FastAPI；配置非法则启动失败；缺少可选提供者时可降级；真实研究默认禁用演示数据。 |
| R02 | 个股数据 | 统一股票身份，保留时间/来源/质量；过期、非有限、错股票和错周期数据不得进入有效图表或信号。 |
| R03 | 研究分析 | 技术、财务、估值和事件分别解释；数据缺失明确表示，规则输出确定且可回放。 |
| R04 | 工作台持久化 | 普通浏览不发布正式建议；符合盘后来源和时间条件的队列结果可追加历史。 |
| R05 | 自选/笔记/预警 | 写入原子且身份正确；未知预警状态写入结果不记为成功；导航不取消已提交写操作，失败保留草稿。 |
| R06 | 问答与策略输入 | LLM 只解释确定性证据；数值/行动本地验证，总超时有界；自然语言策略必须通过有限语法和字段约束。 |
| R07 | 全市场扫描 | 先验证市场覆盖，再执行有界并发与重试；单股缺失与提供者链故障不同；中止后不写虚假成功。 |
| R08 | 正式评分 | 使用唯一当前规格；原始分、展示排名、研究概率不同；所有发布结果可按冻结规则回放。 |
| R09 | 筛选/导出 | 对同一冻结结果使用相同严格 ScreenSpec；分页、近似条件、缺失统计与 Excel 元数据一致。 |
| R10 | 研究概率 | 来源/日历/样本/成本/成熟度必须一致；未通过样本外与独立授权的结果只能作为研究诊断。 |
| R11 | 策略实验室 | 保存版本化策略、冻结候选与来源身份；模拟和证据读取不得触发券商下单或自动取得正式权限。 |
| R12 | 复盘 | 计划修订采用比较后写入；评估为追加尝试；绑定当时计划与建议；不能使用未来信息。 |
| R13 | 导入/备份 | 导入提交绑定成功预览；修订与外键一致；备份验证通过后才允许恢复或破坏性重置。 |
| R14 | 生命周期 | 同数据库只有一个后台所有者；停止有界，旧任务未静止时不释放租约；无阻塞调用占用事件循环。 |
| R15 | 安全 | 浏览器写操作与显式刷新校验来源；敏感响应禁缓存；错误脱敏；凭证与本地记录不泄漏给无关远端。 |
| R16 | 可维护性 | 领域依赖无环且方向固定；不留测试专用生产兼容层；函数复杂度、类型、覆盖率和文档漂移门槛持续执行。 |
| R17 | 前端可靠性 | 读请求 latest-wins，重复绑定可释放，页面隐藏停止无效轮询；可访问性与跨浏览器交互通过回归。 |
| R18 | 数据保留 | 清理只处理允许删除的无引用完整图；迁移不提升历史数据可信度；运行时不读取文档里的样本。 |

## 交付标准

修改必须通过相关行为回归和[完整测试门槛](TEST_PLAN.md)。删除必须同时核实生产入口、CLI、动态加载、模板、测试夹具与持久化消费者；只验证旧名称相等的测试应随兼容层删除，风险与行为测试继续保留。

项目是本地研究应用。在线数据源可用性、账户授权与模型投资表现不由离线工程测试证明。
