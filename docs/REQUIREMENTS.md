# 当前功能要求

本文件记录可验收行为。具体 API 字段由模型和自动生成的 [API 参考](API_REFERENCE.md)定义；实现分层见[设计](DESIGN.md)。

策略模板可载入8个研究草案；目录修订日不能展示成行情日期或有效样本数。跳5日动量、ATR、下行半偏差和回撤条件须使用已复算且绑定的冻结特征，无法验证就拒绝筛选，不补零。新增指标不自动改变生产排名。定时策略过期提醒按交易会话计算，节假日和日线发布边界应与实时执行准入一致。详细因子与策略边界见[量化因子与策略](QUANT_FACTORS_AND_STRATEGIES.md)。

| 编号 | 范围 | 验收要求 |
| --- | --- | --- |
| R01 | 本地启动 | 单 worker FastAPI；配置非法则启动失败；缺少可选提供者时可降级；真实研究默认禁用演示数据。 |
| R02 | 个股数据 | 统一股票身份，保留时间/来源/质量；过期、非有限、错股票和错周期数据不得进入有效图表或信号；既有硬异常对主动信号的限制不能被较高质量总分覆盖，建议与策略输出须一致。分钟时间按完整ISO偏移转上海时间后判断新鲜度和未来边界，不能截掉时区或损坏后缀；无偏移仍为上海时间。分钟缓存与提供者先排除无效观测，再按真实时刻排序、去重并选取最近条数；自动清理保留真实较新记录，失败降级在取条数前排除未来记录；图表横轴显示上海时间，日线日期和检查器来源原文保持。板块与分钟缓存还须检查请求覆盖，新鲜但未覆盖较大请求时回源；来源已观测的短响应可在原TTL内有界复用，失败仍明确降级。 |
| R03 | 研究分析 | 技术、财务、估值和事件分别解释；数据缺失明确表示，规则输出确定且可回放。原行情估值至少有一项有限非零 PE/PB，市值或价格位置不能使缺失估值可用，规模不直接加估值分；PE/PB 历史与同行分位排除晚于行情或时点无法核实的样本，排除后仍须满足原样本门槛。做T只在实际发布价位严格围住现价且实际区间满足原宽度要求时生成执行步骤。 |
| R04 | 工作台持久化 | 普通浏览不发布正式建议；符合盘后来源和时间条件的队列结果可追加历史。 |
| R05 | 自选/笔记/预警 | 写入原子且身份正确；笔记修改/显隐/删除须核对完整状态令牌，旧状态 409 且保留草稿供明确对照恢复；价格和日期明确且本地身份可验证时可零报价创建，其余维持原默认值；笔记缺省交易日期时，图表按创建审计时点对应的上海日期标注，清空日期不使可见笔记丢失标注；未知预警状态写入结果不记为成功；导航不取消已提交写操作，失败保留草稿。预警编辑的旧保存回执只结束原提交仍未变化的编辑，期间新增草稿及取消重开的编辑保留；正常列表回读不得丢失仍属于同一规则身份的编辑，删除或身份替换不继承旧草稿。笔记写入的内部回读/模型构建在提交前完成，失败回滚；已确认提交后，独立列表回读失败保留确认项并明确提示，未知列表不显示为空。自选可按文本、研究状态、上海日期下的到期复核及未读变化组合筛选，只改变显示，保留完整队列、订阅、未读水位和编辑草稿。普通查看图表不清除未读；显式查看变化且当前股票记录成功可见后，才按已显示水位标已读。迟到或重复确认不得增加未读数，新建议变化仍计入。新建告警在写入前校验完整条件；修改条件类型或阈值时，在同一写事务核验最终条件组合，并发语义修改不得提交非法组合；旧条件异常记录仍可独立管理名称、备注、启停等元数据，不因此修复或认可其原条件。 |
| R06 | 问答与策略输入 | 按支持的问题范围和当前字段证据判断可答性；事件空状态提示不构成事件证据，也不生成事件标注，真实观察事件保留；缺来源或不支持的问题明确说明、无交易动作且不调用 LLM。LLM 仅选择排序本次已有证据，版本/上下文/规则绑定本地验证，服务端渲染事实，总超时有界；自然语言策略必须通过有限语法和字段约束。做T已被阻断时，问答不得重新拼接主动执行参考句。 |
| R07 | 全市场扫描 | 先验证市场覆盖，再执行有界并发与重试；单股缺失与提供者链故障不同；中止后不写虚假成功。TOP100快速更新仅豁免全市场覆盖分母，仍执行既有快照时效及信封完整性要求。 |
| R08 | 正式评分 | 使用唯一当前规格；原始分、展示排名、研究概率不同；所有发布结果可按冻结规则回放。合法零分与缺失证据分别处理，负面条件不反向提升证据分；全市场同一已完成快照的盘前/官方评分保持一致。纯趋势比例计算不因合法价格单位缩放改变贡献，历史子算法按冻结身份校验；有效零真实区间计入 ATR 窗口分母，非法高低价不能生成派生卖压证据。完成快照评分前须核对昨收口径；Alpha 的观察、等待和未知状态不默认提供正向支持。 |
| R09 | 筛选/导出 | 对同一冻结结果使用相同严格 ScreenSpec；分页、近似条件、缺失统计与 Excel 元数据一致。历史批次可轻量翻页，失败保留原页与选中批次；选中后仍核验冻结身份。方案另存创建副本，更新显式绑定 ID 与修订；列表按需分页并保留选择，同一响应总数和条目来自同一只读快照，不能用无法完整表达的表单覆盖旧条件。全部入队在单次收集内固定页大小，核验完整数量、跨页唯一性与来源版本后才提交，窗口缩放不漏股；筛选改变淘汰旧收集。同一股票、来源批次、方案ID和修订的重复入队返回既有来源回执，不重新修改用户当前研究状态或元数据；首次及新来源按原入队规则处理。已记录筛选变化可只读回看来源批次、方案修订和三类股票明细，历史不随当前方案修改，查看不重跑扫描或产生新事件。 |
| R10 | 研究概率 | 来源/日历/样本/成本/成熟度必须一致；未通过样本外与独立授权的结果只能作为研究诊断。 |
| R11 | 策略实验室 | 保存版本化策略、冻结候选与来源身份；确认写入后独立呈现读回状态，避免重复创建；候选页码／排序仅成功读取后变更。已保存策略和执行历史可分页查看，列表翻页保留当前草案与已载入身份；可只读打开单次历史执行及其已保存纸面委托，响应须匹配所选执行和来源指纹，查看不重新执行、不授予历史对象新的写入资格。已保存定时任务可按当前载入策略分页查看和逐项启停，保持固定版本，创建及重新启用在同一写事务核验源策略归档状态和固定版本，归档先提交则拒绝启用；禁用任务不依赖源策略可读，查看不触发执行。调度取得执行权时在写事务内再次核验当前状态与版本，停用或归档先提交则不创建新执行；已取得执行权的任务保持原收尾语义。编辑输入立即使旧执行资格失效，最新编译及确认保存内容一致后才能执行、回放或新建任务。纸面委托草案可审阅来源、股数、金额和退出约束，不自动进入复盘账户。模拟和证据读取不得触发券商下单或自动取得正式权限。组合买入费用计入现金预算，合法数量取整后仍满足实际最低持仓金额；新分配语义进入执行指纹，旧封存执行只读。 |
| R12 | 复盘 | 到期队列服务端筛选后分页，返回完整筛选数量、成熟截止时点和跨页内容身份；计划或最新评估变化时要求重新读取，不能把前200条或失败响应当作完整集合。到期模式独立展示同一响应中的计划与评估，翻页失败保留成功页并允许重试，筛选变更淘汰旧响应；全局统计及每次最多100条的批量评估须说明范围，不受当前筛选或页码影响。已定位卡片的焦点应在普通列表迟到重绘后保留；用户已主动移焦或卡片消失时不抢焦点。计划修订采用比较后写入；保存回执仅重置仍属于原提交的未变草稿，期间切换计划或新增输入必须保留。同一计划继续编辑时采用已确认的服务端修订作为下一次提交基线；评估为追加尝试；绑定当时计划与建议；不能使用未来信息。追加读取更早计划失败时保留既有列表、编辑草稿和分页偏移，显示就地错误并允许重试；失败及取消不推进偏移。全局看板按 ID 精确定位指定计划，不受个股最近一页限制；严格核验股票身份，过期响应不覆盖最新选择，不破坏普通历史分页。模拟运行对比绑定当前看板操作与两侧选择，后续操作或选择变化取消旧读取，旧成功或失败不覆盖新反馈；账户和模拟写入独立完成。模拟账户资金修改的历史检查、写入和返回模型构造在同一写事务，历史先提交则拒绝改资金，失败完整回滚；资金冻结后仍可独立保存默认成本；模拟策略的插入与返回模型构造同事务，内部回执或提交失败时回滚，允许同计划版本重试；已进入不可变运行的策略不能删除。模拟卖出所得与现金不足以支付完整费用时保留持仓和首次退出意图，记录原因并等待重试，不允许实际现金透支。 |
| R13 | 导入/备份 | 导入提交绑定成功预览的文件、模式及旧来源时区；等待提交时不开放第二次提交，操作收尾后按当前预览恢复按钮，已失效预览不能被外层任务重新启用；无明确时区的旧时间不自行推断，用户可显式填写后预览。修订与外键一致；备份验证通过后才允许恢复或破坏性重置。成功恢复与replace导入在新历史安装时切换预警流身份，失败回滚保留原目标身份与数据；merge、dry-run和普通重启不换代。恢复只在受限暂存库修改通知元数据，原备份字节保持不变，派生验证不得放过业务数据修改。导入、导出和状态摘要在初始化失败、正常及异常离开时均显式关闭SQLite连接，保留原事务结果。 |
| R14 | 生命周期 | 同数据库只有一个后台所有者；停止有界，旧任务及其同步线程未静止时不释放租约，并行子项异常后完整收尾；无阻塞调用占用事件循环。仍活跃的手动任务不得在重启时被当作孤儿取消；协调器暂拒激活后可在真正静止后重试。自动扫描预检不阻塞普通到期任务，至多一个预检任务复用原停止与释锁协议。工作台默认最多 4 个未完成构建任务，含缓存清理后存活的旧任务；缓存命中和复用当前同股票共享任务不占新额度，关闭后拒绝新读取。provider同步抓取的等待者取消后，相同请求可加入仍可等待的原任务；不同请求与取消收尾仍受原背压，不重复启动抓取。 |
| R15 | 安全 | 所有 `/api` 请求（含只读）均核验 Host 对应来源是否受信任；存在 Origin 时校验 Origin，否则依次使用 Referer、Sec-Fetch-Site 检查浏览器来源。无浏览器来源头的请求仍须通过 Host 检查；敏感响应禁缓存；错误脱敏；凭证与本地记录不泄漏给无关远端。 |
| R16 | 可维护性 | 领域依赖无环且方向固定；不留测试专用生产兼容层；函数复杂度、类型、覆盖率和文档漂移门槛持续执行。 |
| R17 | 前端可靠性 | 读请求 latest-wins，重复绑定可释放，页面隐藏停止无效轮询；取消读取后控件可恢复；刷新失败保留原界面时，问答结束须恢复原请求拥有的表单，旧请求不得释放新表单或新请求的忙碌状态。停用通知须中止当前客户端读取和后续分页，重新启用时旧收尾不覆盖新请求，取消后不交付通知或推进游标。预警增量游标绑定持久流身份，恢复后较小ID的新事件可正常交付，分页中换代不混合交付，旧响应不能覆盖跨标签页已观察的新流；旧版首次升级明确建立当前基线且不补发历史，保留通知开关。单条桌面提醒点击可打开相关股票的笔记预警页，展示通知捕获时的只读记录；不按可能复用的事件ID查询新历史，摘要只表示批量数量，不虚构单股。后一次导航优先；当前行情失败时保留原通知内容并区分旧分析回退，普通导航清除详情。运行状态诊断仅在所属页面可见时加载和轮询，离开后旧定时器不能恢复读取；清理预览由显式按钮触发，执行仍重新核验。诊断刷新失败明确显示历史结果，下次成功清除警告。个股、选股、复盘、自选和系统维护分区明确；各区保留子页位置，旧浏览器偏好随页面归属迁移。笔记预警保持当前股票上下文，不夹带全局维护操作。股票搜索的组合输入按键不触发应用选股或建议导航；可访问性与跨浏览器交互通过回归。 |
| R18 | 数据保留 | 清理只处理允许删除的无引用完整图；公开清理的扫描删除与其它表变更在同一真实事务中提交或回滚，可选空间压缩必须在提交和连接工厂恢复后执行，压缩失败不伪装为删除失败；迁移不提升历史数据可信度；运行时不读取文档里的样本。 |
| R19 | 扶摇研究数据 | 标准配置默认关闭，只有显式同步任务访问供应商；专用本地启动入口可发现受保护密钥文件，环境显式值优先，不将凭证传给浏览器、日志或下载主机。REST 同时检查 HTTP 与业务码，限流、失败、权限不足分别处理，每次尝试先占用项目持久预算。财报按股票/期间对齐原值并显示来源、币种、单位缺口及观察时间；有限财务问答只引用已有事实，不计算未经核实的财务评分或推断历史披露资格。估值保存同口径本地观察，PE TTM / PB MRQ 经身份、摘要及时间校验且至少一项有限非零后，可共用一份结果替换当前个股总览原基本面槽及估值分析；获取超过7日或未来观察拒绝，批次时间存在时同样不得过期或晚于获取时间；数值脏值拒绝，零值/缺失不加分也不重新归一化，负值保留并按风险规则减分。既有阈值仅为启发式估值规则，不新增因子，不混入行情历史/同行分位；不可用时沿用原行情并说明原因，读取不触发远端请求。价值研究摘要复用已准入估值，覆盖仅计两项输入，正倍数倒数须有限且不当作投资回报；财报按所选期间与实际来源时间显示三个合并字段符号，同年度三表完整且字段唯一时才作利润/现金流联合提示，缺失、重复或异常不形成正面结论。摘要独立于行情批次，不改工作台评分、全市场排名或历史证据。板块成员仅代表当前，情绪分页须完整一致。未复权 Parquet 全量/增量在独立目录分批校验后原子发布，日线同键异值、日期缺口、坏文件或失败不得切换当前版本；企业行动仅合并完全相同的行，同日不同记录保留并标注歧义，缩股保留原比例且不自动复权；重复幂等，修订可追溯，下载不转发 Key。离线导出保留摘要并明确未取得 PIT/正式执行准入，不修改现有前复权缓存或全市场选股权重。页面读取本地记录，旧股票响应不得覆盖当前对象，同步任务保存原始参数并逐项原子提交观察与成功进度；支持按ID查看、主动停止和显式补做未完成股票，同一父任务重复补做返回同一个子任务。正在停止期间不接受新同步，历史任务显示真实阶段和已知数量，旧记录缺少参数时不得猜测补做。任务关闭须先完成已拥有工作和状态收尾；筛选保留展开状态，过期任务回执须按ID核实。 |

## 页面恢复与按需加载

启动时从已校验的研究历史首条恢复上次成功加载的股票，失败选择不覆盖历史；无历史、无效存储或清空历史后使用原默认股票，不把行情、凭证或研究数据另存入页面偏好。

系统维护和自选监控不自动请求隐藏个股的工作台、分钟分析、概率或复盘记录；系统仅读取数据状态和可见子页，自选保留队列、观察池、行业背景及报价流。研究与复盘继续拥有个股上下文，切回时只恢复一次读取，显式股票导航优先。重复选择自选页及浏览器恢复不得使报价流永久断开；成功写入后的列表回读同样恢复订阅。隐藏页记忆的财务/模拟子页不能触发读取。

全市场实验模型和上涨概率研究默认折叠在“高级概率研究”中，历史回放也默认收起；键盘可展开，折叠不清空已选周期、证据和实验开关，不改变正式榜单及数据资格。手机扫描控制和股票操作按钮须完整可见。

## 冻结候选对比

全市场榜单及方案结果允许选择同一冻结批次的2–4只候选并排对比。同批次分页保留选择，切换批次、模式或摘要后清空；对比选择与研究队列相互独立。请求必须绑定页面的快照摘要，返回数量、证券、顺序、来源及合同严格一致；缺失行明确解释，不存在的证券拒绝。风险分较高表示风险较高，研究维度和生产分不解释成收益概率。

仅看差异保留身份及来源上下文，零值不混同缺失。导出只包含当前已验证对比结果；选择变化、加载、失败、关闭或销毁使旧响应与导出失效。对比读取同一SQLite快照，不调用当前行情或供应商，不修改排名；历史回填或动作来源不合格可按原有审计语义查看，不因此取得执行资格。

## 筛选条件解释

工作台解释必须绑定已经成功展示的完整筛选条件、方案修订及冻结批次身份；表单里尚未应用的草稿不改变解释。同批次换方案、读入中或读取失败时不能保留冒充当前条件的旧解释，返回的条件及批次与原请求不匹配时拒绝展示。无法精确对应原始冻结规则的概率阈值或v6生产重排明确不支持，不悄悄忽略条件。

普通查询和保存方案的迟到响应不能相互覆盖当前榜单；普通后台刷新不能替换当前应用的方案。批次没有变化的健康轮询及页面隐藏再恢复保留已确认的列表和解释，离开页面后的未完成读取不得恢复过期列表。

每个条件显示保留其他条件、只移除该条件后的总命中、新增命中及其中原值缺失数；仅恰好违反一个条件的股票计入新增，多条件失败不误计，零新增不省略。范围表示整个上下限区间。最多3个按当前排序的示例保留原值、状态与缺失；示例及分页截断不改变总体计数。顺序漏斗、重叠排除原因和独立影响分别说明，解释不自动修改筛选或保存方案。

标准和保存方案的真实零结果均提供就近解释入口，打开并聚焦工作台。无可信批次、加载或失败不能伪装为空筛选。解释只读本地冻结结果，不新增供应商采集、评分、扫描或研究队列写入。

## 当前个股分层评分要求

2026-09-14 第二轮的个股全景分使用 `current-stock-overview.v2` 和 `current-market-context.v2`。技术面、量价热度（衍生）、基本面、事件面各固定占1/4方向预算；缺失提供0偏离，其份额不转移，重复或未注册方向因子拒绝聚合。风险面以 `aggregation_role=risk_constraint` 参与实际扣分 `max(0,50−风险面分)×0.25`，不作为第五个方向因子求均值。分别提供扣风险前证据分、非负实际风险扣分、扣风险后方向基分及可靠性；证据覆盖只计参与方向槽位数/4，不是字段完整率或上涨概率，不再作为可靠性乘数。旧响应缺少新增解释字段时兼容显示。

沪深300固定使用 `000300.SH`；主行业从最多100项的完整行业页唯一精确匹配，不以热门子集、近似名称或同名冲突推断归属。行业保留 BK 指数代码与真实行情事件时刻，获取时间独立；SQLite冷暖读取一致，旧行缺失保持 NULL。

行情事件须与个股报价为上海同一交易日、不晚于个股报价或评估时刻、落后最多300秒；行业事件还须不晚于获取时刻，获取时刻不晚于评估时刻。未来、过期、缺失、回退、演示或不符合已支持来源/身份的观察不得参与对应修正。缺少行业不产生相对强弱证据，缺少市场不产生行业相对市场证据；保留可用层并解释缺失，不将缺数当作零涨幅或正面证据。

有效行业的同日相对涨幅按每1个百分点5分映射为有界相对强弱 R。对方向基分 B 使用 `T=clip(B+0.2×((R−50)/50)×abs(B−50),0,100)`；20%限制既有方向偏离的调整幅度，不是两份方向分的混合权重。无行业、无超额或 B=50 时保持基分，修正连续且不翻转原方向，展示实际加减点。大盘与行业相对大盘分别以 `[0.5,1]`、`[0.7,1]` 的乘数约束正向偏离；可靠性最后乘以相对50的偏离幅度，低可靠性向50收缩，高质量不能将偏空证据直接加成看多。完整公式见[设计](DESIGN.md)，参数是预先选择的工程规则，没有最优性证据；信号证据与可靠性也不是校准概率。

风险面从50减纯价格风险/有效卖压惩罚，原分析风险等级和动作门禁仍受质量约束；量价方向不混入质量数值。事件面以50为中性，按去重后的可计分积极/风险记录加8/减10；“行业”“数据”“观察”“异动”“历史复盘”类别保留展示但排除方向聚合，没有可计分记录时保持槽位不可用。龙头复合观察保留解释，但不再次进入因子实验室综合分或独立校准因子计数；其他因子也不因此被证明统计独立。

全景量价热度使用 `current-price-volume.v2`，以 `50+clip(涨跌幅×5,−40,40)×clip(相对量比,0.5,1.25)` 取整并限定0–100；成交额和换手率不提供方向奖励或充当可用性门槛。现价和昨收须为有效正数，报送涨跌幅与价格重算值相差不超过既有0.3个百分点容差；通过后使用价格重算涨幅，矛盾或溢出数据不得提供方向。仅正式分析且完整报价时刻为上海15:00及以后时，可用当日正有限成交量除以前5个严格早于报价日的有效日K均量；同日K不入基线，缺量不能跳过补足，日期重复、乱序、未来或不足窗口明确不可用。当前量缺失只能由同日有效日K补充；样本有效不等于已经证明连续交易日或历史PIT。5日/10日连续性对严格涨跌对称计分，平盘保持50、窗口不足明确说明；它与因子实验室的20日量价确认规则分开；对应的量价热度历史因子与当前共用v2公式。

本轮范围是当前个股全景分及复合因子去重。正式全市场 v5 不采用新上下文，历史记录按原规格读取，已保存的个股 v1 上下文仅读原结果、不用 v2 重算；新分数不得冒充上涨概率、风险调整 alpha 或已验证收益预测。外部板块本次在线核验未成功，离线通过不能替代真实源可用性证明。

## 冻结评分后续跟踪

离线评分跟踪须先固定同版本扫描及高低分组，再关联后续行情；同分不按证券代码拆开，缺失结果不重新分组。同日重扫不增加时间样本，版本身份未知不得合并形成有效性证据。报告区分尚未到期、已到期缺失、不可比较与同日配对；至少达到日期/覆盖阈值且时间轴完整才展示区间。结果只描述冻结排名分的毛价格变化，不授予概率、收益保证或发布资格。命令生成可直接打开的本地 HTML 与 JSON，详见[评分跟踪](SCORE_TRACKING.md)。

## 交付标准

工程可靠性要求：全市场重验证读取关闭后拒绝新任务，重复取消和关闭子任务首次调度前取消都不能使资源先于已准入读取结束而关闭；已完成任务的回调尚未执行时不得忙循环。共享 SQLite 初始化失败须立即释放连接；自选写入的内部回读和模型构造失败须回滚，保存时必须保护需保留的并发字段。新增提醒/笔记成功回执不得清空已更改类型的同值草稿。

评分合同要求：下行风险采用明确零目标、全观测分母、日频单位的历史目标下行偏差，持续同幅亏损及单次大跌不得在该项中被误算为零；当前量价分与其历史校准使用同一规则、窗口和两位量比输入。算法换代须隔离旧模型与新特征，冻结主评分保留原语义，不能静默重解释历史或自动取得投资有效性证明。

策略模板对照须先使用同一完整冻结股票池、原始发布封印及绑定的PIT因子固定三套候选与目标权重；按评分合同与共同日期隔离比较，不用后来的同日重扫替换首批失败。v2须区分D至D+H固定权重毛收益、D+1开盘至D+H+1收盘的独立批次净收益，以及选择诊断。毛收益空篮不配对；净执行中明确的无交易草案可作为零收益现金情景。缺失执行路径或固定退出失败使整篮不可用，不补位、不重分配、不将未知当0；明确未成交预算留在现金。

净执行须经固定注册表、独立摘要、原始交付目录和会话目录四件套的严格加载器校验，费用计入预算，按官方未复权价格重新取整股数。压力情景为佣金率/最低佣金各1.5倍、双边滑点各加10bp，股数重新计算；独立批次回撤不得称为连续账户回撤。可选`--non-overlapping-signals`须在收益读取前按每合同首日及可信日历每H+1会话固定锚点，与显式批次ID互斥。统计须独立核对完整日历，任一成熟锚点缺失就阻断推断；至少20个完整锚点后使用2000次、块长2锚点的循环移动块bootstrap及三对Holm校正。这些是工程研究门槛，不是论文保证。

报告须分别显示诊断领先、统计优势与采用资格，不能把均值较高或统计显著当成未来胜出证明。当前回溯流程的`adoptable_template_id`始终为空，不保存执行、改变排名或覆盖用户自定义策略。只读离线报告的完整口径见[策略模板对照](STRATEGY_TEMPLATE_TRACKING.md)。持有期限与调仓间隔是两个独立字段，载入及再次编译必须各自保持，计划间隔不代表已实现自动调仓。

全市场概率排序的 DSR/PBO/组合回撤必须具有相应试验、依赖及账户证据；零基准 PSR、交错分块的条件比较或重叠持有期收益链不能冒充这些证据。缺失时明确不可用、阻止新晋级；旧发表和回滚仍可审计，旧控制不得授权新发表。性能优化须保持现金、整手、费用和容量结果，以及全批筛选/排名验证；分页不得序列化随后丢弃的全批明细，数量搜索工作量须有界。

修改必须通过相关行为回归和[完整测试门槛](TEST_PLAN.md)。删除必须同时核实生产入口、CLI、动态加载、模板、测试夹具与持久化消费者；只验证旧名称相等的测试应随兼容层删除，风险与行为测试继续保留。

项目是本地研究应用。在线数据源可用性、账户授权与模型投资表现不由离线工程测试证明。

## 预测规则与证据解释补充（2026-09-15）

当前量价热度与历史同证据必须同分；历史校准需绑定评分版本，缺失或不可比输入不能生成中性样本。固定D+5/D+10收益窗口内的公司行动不可直接解释为盈利或亏损；现合同无法证明调整基准时整样本拒绝。证据充分度不随看多方向或历史盈利奖励，缺失份额保留为0、删除稀少证据不能抬高充分度；零样本与单样本不能显示较高可靠性。历史场景不得按最高收益挑选为当前依据。

未来预测必须区分收盘方向、扣费盈利与相对基准事件；评价同时展示简单基准和同日选股能力，高概率子集单独诊断。日期相关性与标签重叠不因股票数多而消失，缺日期不能压缩成相邻重采样块。已有历史窗口的复跑不能当新的独立证据，离线诊断不自动修改模型或晋级。可执行阶段与条件见[预测改进方案](PREDICTION_IMPROVEMENT_PLAN.md)。
