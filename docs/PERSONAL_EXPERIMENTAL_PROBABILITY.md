# 个人实验概率筛选

此功能是用户明确选择的独立实验模式，不是正式概率筛选或 v6 生产排名晋级。
在“全市场选股”的“历史模型概率筛选与实验排序”中勾选“我了解局限，开启个人实验”。
可按最低实验概率、市场、代码/名称筛选，按实验概率或原始排名排序并分页。
“预测目标”可切换 D+1、D+2、D+5 收盘上涨，以及旧版 H5 扣费盈利模型；界面默认选择 D+1。
刷新页面默认关闭，实验阈值不会写入正式筛选条件或已保存的正式策略。

## 概率含义与限制

- D 是榜单使用的已收盘日线日期。D+1/D+2/D+5 分别判断固定第 1/2/5 个交易日的**前复权收盘价 > D 日前复权收盘价**。
  持平计为未上涨；各周期都相对同一个 D，不是相对前一天，也不是要求连续上涨。不扣交易费用，不表示买入后盈利或可成交。
  节假日按可信交易日历跳过；目标日缺失、无成交量或契约不一致时排除样本，不顺延到下一根有行情的日线。
- 旧版 H5（不是 D+5）：假定 D+1 开盘买入，D+6 收盘卖出，按历史研究的成本模型扣费后**绝对净收益为正**。
  不是跑赢市场的概率，也不是实际成交概率，不与正式联合执行概率混用。
- 四种模型共用已有 Tencent/qfq 的 11 个 OHLCV 特征；D+1/D+2/D+5 从已验证的静态历史库重新构建收盘方向标签，
  H5 仍使用原历史回放，而非把 Choice 不复权数据直接替换到旧模型。
  历史抽样、存活偏差、复权版本、停复牌、涨跌停、成交容量、公司行动和全市场泛化局限仍然存在。
- 离线先完整重放验证来源，再分别用最晚 40 个成熟信号日独立拟合 Platt 校准器。
  训练部分保留至少 120 日；D+1/D+2/D+5/H5 分别隔离至少 1/2/5/6 个信号日，并要求每个训练标签严格早于校准首日。
  拟合校准器不代表模型通过了样本外验证；原历史 OOS 的失败和不确定性原样保留。
  线上收盘方向模型内的 OOS 状态仍为 `not_evaluated`，不能借用 H5 的 Brier Skill、校准器或验证结论。
  新增 Choice 的独立时间隔离报告只验证该报告中重新拟合的研究模型，不能自动改变线上模型的证据状态。
- 当前输入仅取截至榜单 `data_date` 的 21 根同一 qfq 契约日线。盘中榜单使用前一完整日线，
  不使用尚未收盘的当日日线，不把实验结果称为当时已知的 PIT 预测。
  D+1/D+2/D+5 的 21 根输入还须与训练相同，恰好覆盖以 D 结束的固定交易日历窗口；缺日不会用更早日线补位。
- 缺少当日或 21 根日线、契约混杂、信号日无成交量，或某个标准化特征超过 8 个训练标准差，
  该股票不输出概率、不参与实验排名，展示缺失数量和具体原因；不会用 0 或 50% 填空。
- 信号日必须晚于模型所有已使用标签的截止日；模型对该日线日期的最大标签年龄为 90 个自然日，
  到期需要新历史重建，不能通过更改生成时间自动延期。
- 实验排名只是可计算样本内按概率降序、代码升序的稳定排序；筛选不重写其全样本排名。
  原始分数和排名只读保留。正式 API、导出、策略、自动化和 v6 控制不消费实验结果。

## 构建与调用

离线生成（可能需要数分钟进行完整回放；GET 请求从不训练模型）：

```sh
.venv/bin/python tools/build_experimental_probability.py \
  --source data/research/market_scan_probability_replay/market-scan-probability-historical-replay-2024-11-01-2026-07-23-f4a32fd5c4f37505a5143f930b8d879ff32da0d98ba207ef050f1a6dfa8e074e.json
```

产物保存在 `data/research/personal_experimental_probability/experimental-h5-<sha256>.json`。
独立 D+1/D+2/D+5 构建命令（仅读本地静态历史，不登录数据商）：

```sh
.venv/bin/python tools/build_experimental_probability.py --prediction-kind close_d1 \
  --history-manifest '<VERIFIED_HISTORY_MANIFEST>' --database '<MATCHING_STATIC_QFQ_SQLITE>'
.venv/bin/python tools/build_experimental_probability.py --prediction-kind close_d2 \
  --history-manifest '<VERIFIED_HISTORY_MANIFEST>' --database '<MATCHING_STATIC_QFQ_SQLITE>'
.venv/bin/python tools/build_experimental_probability.py --prediction-kind close_d5 \
  --history-manifest '<VERIFIED_HISTORY_MANIFEST>' --database '<MATCHING_STATIC_QFQ_SQLITE>'
```

对应产物为 `experimental-close-d1-<sha256>.json`、`experimental-close-d2-<sha256>.json`、`experimental-close-d5-<sha256>.json`，与原 H5 分开保存和选择。
历史 manifest、全部日线、交易日历及标签输入摘要均绑定；拒绝活动 SQLite 的 WAL/SHM/journal 文件及构建中发生的源文件变化。
模型缺失、过期、损坏或目标不符时只报当前目标不可用，不回退到其他周期。
所有产物都做有限 JSON、完整结构及文件名/内容摘要校验；目录中有损坏文件就拒绝使用。
选择标签日期最新的版本，同日期再按生成时间选取；这是本地内容完整性，不是独立机构签名。
模型文件与历史原始包单独备份，均不提交到代码仓库，也不重写旧研究文件。

### Choice 独立候选与时间隔离回放

Choice 原始日线与 `TAFACTOR` 可通过[独立转换流程](CHOICE_RESEARCH.md#复用已有日线做独立方向研究)
生成专用历史库，再显式传 `--choice-history-manifest` 和独立 `--output-dir` 构建候选模型。
转换器验证来源回执、完整日历和逐行转换，排除不可用交易日，不冒充 Tencent 的前复权契约。
因为两种数据源可能采用不同复权算法和成交量口径，候选模型禁止自动覆盖现有线上模型。

`tools/validate_experimental_direction.py` 固定同时报告 D+1/D+2/D+5：共同最后 60 个成熟
信号日测试、各自 40 日校准、至少 120 日训练、周期对应的两段隔离。
它报告按日等权的概率评分及简单基线，不使用最终测试集调参、挑周期或校准。
产物独立于模型文件，`completed` 表示评估完成而非达到正式门槛。
既有历史可能被先前研究看过，因此只能称历史隔离回放，不是从未见过的前瞻样本外验证。

显式确认的独立只读接口：

```text
GET /api/market-scans/141/experimental-probability?acknowledge_experimental=true&min_probability=0.4&sort=probability&page=1&page_size=50
```

参数 `prediction_kind=close_d1|close_d2|close_d5|net_h5`，API/CLI 省略时保留 `net_h5` 以兼容旧调用；界面明确发送所选目标。
响应明确返回目标、参考价口径、固定交易日偏移及实际目标日期。切换目标会取消旧请求、清空旧结果并回到第一页；
筛选和排序只消费当前目标的概率，迟到的其他周期响应会被拒绝。
编辑筛选条件立即取消旧请求并清空列表，点击应用后从第一页查看；上下翻页只能沿用已应用条件。
翻页还绑定批次、信号日、快照摘要、模型摘要和当前行情输入摘要；版本改变时要求重新应用，不拼接不同版本的结果。
界面显示各模型校准期正例占比；不同目标的概率不表示可直接比较的收益率，也不构成有效性证据。

`acknowledge_experimental` 缺失或为假时返回 422。
返回的 `formal_filter_qualified` 恒为 false、`production_ranking_effect` 恒为 none，
并包含来源模型摘要、当前输入摘要、原始榜单摘要、样本外研究指标和逐项覆盖情况。
它与 `/results?min_upside_probability=...` 的正式授权门禁完全独立。
每次请求都在单一只读事务中重新核对**全榜单**发布摘要，再读取实验所需的名称、市场、原始分数和排名。
不重复运行全市场生产评分解释重放，不缓存授权，也不改变正式读取验证；即使修改实验未使用的字段，摘要校验仍会拒绝。
界面遇到带 `Retry-After` 的 503 校验繁忙响应会有限重试，整个读取/重试预算 90 秒，关闭实验或切换榜单会取消后续重试。
正式榜单尚在慢校验时，实验区可用非授权导航定位当前模式或用户所选的全市场批次，再由实验接口独立全量验签。
明确选择的历史批次失效时不回退到另一个批次；不会将导航身份提升为正式榜单、导出或生产排名授权。
历史列表更新或正式历史读取失败导致界面回退选择时，实验区同步取消旧选择，迟到结果不留在新选择下。
实验查询在独立、只读的 Python 子进程中完成相同的全量快照校验与预测，避免冷启动 CPU 校验线程与
SQLite 逐行读取争抢同一个 Python 执行锁。实验区有独立的单请求准入通道，正式读取保留原单请求通道；不并发堆积实验子进程，每次最多 60 秒，
超时会终止并回收子进程，错误类别保留，不使用旧结果或绕过校验。此隔离不改变正式榜单读取路径。
