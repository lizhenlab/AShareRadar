# 离线工作区备份与恢复 Goal

状态：已完成并验收（2026-10-15，Asia/Shanghai）。本轮与前两轮结果分别保留在[测试计划](TEST_PLAN.md)。

## 可直接交给 ChatGPT / Codex 的目标

交付 AShareRadar 显式范围驱动的离线备份创建、独立完整性校验和新目录恢复能力。复用现有 SQLite 一致快照及通知流恢复规则，明确可验证的局部租约与外部停写前提，有界复制并核验文件、清单和已知领域引用。明确主库、扶摇、研究及封存运行目录的覆盖与搬迁限制，不能将缺失引用或未受保护的活动写入伪称为全域一致备份。使用临时数据完成原源目录移除后的恢复演练，以及损坏、并发、取消、磁盘不足、预算和路径安全回归。保留所有已有改动，不停止生产服务、不执行生产数据备份或恢复、不改写冻结研究，更新 CLI、文档和工程验收。

## 实施与验收

| 范围 | 交付 | 验收条件 |
| --- | --- | --- |
| 显式范围 | 严格 JSON、互不重叠绝对路径根、全部 SQLite 声明及唯一主库 | 未声明 SQLite、重复及越界路径、错误类型和缺失文件拒绝 |
| 离线创建 | SQLite 一致快照、已知写租约、普通文件有界复制、清单最后发布 | 停写声明不冒充自动证明；竞争、源变更、容量不足与取消不发布成功结果 |
| 独立校验 | 成员全集、文件摘要、数据库完整性、已知领域引用机械验证 | 删除原源目录后仍可验证；重算领域结论；验证期间替换或增删成员拒绝 |
| 新目录恢复 | 独占新目录、主库通知流换代、旁库原样恢复 | 已有空目录也不覆盖；原备份不变；恢复后再次完整校验 |
| 操作边界 | 明确覆盖、排除项、预算、外部依赖及不可直接续跑 | 不执行归档 Python、不改冻结摘要及绝对路径；跨域一致性与运行资格始终未验证 |

## 交付边界

- 本轮开始前已保存全部已有源码快照；不重置、不提交或推送用户改动。
- 测试只使用临时数据库、目录和子进程；不停止或启动生产服务，不调用真实数据供应商。
- `offline_writers_stopped=true` 是操作者的外部停写声明；数据库事务及已知锁不覆盖全部历史写入路径。
- `cross_domain_consistency_verified=false` 与 `resume_eligible=false` 是固定结果。恢复出的数据可校验，运行依赖、控制绑定和重新启用仍须独立处理。
- 用法见[工作区备份](WORKSPACE_BACKUP.md)，后续跨域写入协议与可运行恢复见[后续设计](RELIABILITY_NEXT_STEPS.md)。
