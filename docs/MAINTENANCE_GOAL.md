## 已确认问题与可执行计划

1. **策略定时任务的执行准入。**调度器取得启用列表后，停用先提交仍可能创建新的执行和提醒。在取得执行权的 SQLite 写事务内重新检查当前启用状态、策略归档状态和固定版本绑定；已取得执行权的任务保持原完成语义。用独立连接与线程闩锁复现先后次序，并保留来源完整性异常的传播契约。
2. **通知分页请求的生命周期。**停用通知会禁止旧结果交付，但尚未取消网络读取，旧任务仍可继续抓取后续页。为每次轮询建立可取消请求范围，在同页和跨标签停用时终止读取；验证立即重新启用不会被旧任务收尾覆盖，保留游标、换代和跨标签交付规则。
3. **中文输入法的按键归属。**已有股票建议时，输入法确认 Enter 被搜索快捷键当成选股。组合输入期间将相关按键交还输入法，覆盖标准 `isComposing` 和兼容事件，正常键盘选股继续可用。
4. **导入预览失效后的按钮恢复。**导入失败已撤销预览，但外层任务包装器又启用提交按钮。在该操作收尾时按当前有效预览重新呈现按钮，保持服务端预览令牌验证与已发出写入的原有语义。
5. **统一验证与文档。**先确认新增回归在本轮基线失败，再检查修复后的领域用例和真实浏览器流程；冻结实现后执行全量 Python 覆盖率、相关浏览器项目、工程门禁和独立复核。将稳定行为写入设计/需求文档，验收结果写入测试计划。
