# 评分预测能力：修改方案与实施记录

日期：2026-09-15，Asia/Shanghai。原生 Goal 已建立；当前目标见[维护目标](MAINTENANCE_GOAL.md)。本方案区分逻辑修复、可以运行的历史诊断，以及需要未来数据和验证的模型升级。

## 1. “准”必须对应明确目标

当前全景分是研究结构分，没有“分数等于上涨概率”的统计映射。历史相似状态胜率也不是经过独立检验的当前股票预测概率。大盘和行业可以提供状态及相对信息，但给全池加同一个常数不会改变排序，叠加显示不等于新增独立预测能力。

| 现有目标 | 标签定义 | 主要验收对象 |
| --- | --- | --- |
| close_d1 / close_d2 / close_d5 | D收盘后，固定交易日D+1/D+2/D+5收盘相对D收盘上涨 | Brier、log loss、相同日期基准、日期等权同日AUC；不等于买入盈利 |
| net_h5 | D+1开盘代理入场、D+6收盘退出，声明摩擦后收益为正 | 概率质量及成本后结果；日线开盘不自动代表能成交 |
| 全市场 net_excess_positive | 既有冻结标签下，成本后收益超过对应基准 | 同日排序、实际选择集合、共享资金组合结果 |
| 全景/因子分 | 技术、量价、基本面、事件及风险的当前结构 | 输入自洽、去重、缺失、版本；未来预测价值另行检验 |

同日能否排对股票、概率是否可靠、实际持仓是否有经济价值，是三个不同问题。多数日上涨时一直预测上涨，也可能得到较高命中率；不能只以命中率超过50%证明有效。

## 2. 本地证据与已复现问题

已有Choice历史方向报告覆盖60只股票、502个源交易日（2024-07-31至2026-08-25），共同测试信号期为2026-05-26至2026-08-18。该窗口已经被查看过，再跑属于历史诊断，不重新命名为独立未见测试。

| 周期 | 日期等权命中率 | 校准期基准命中率 | 相对基准Brier skill |
| --- | ---: | ---: | ---: |
| D+1 | 50.50% | 53.22% | −0.00320 |
| D+2 | 52.73% | 55.58% | −0.00508 |
| D+5 | 57.97% | 58.09% | −0.00192 |

来源为本地 `experimental-direction-validation-be144bf7fc3badd86a776c621bbe561ae9afddf4adae548e40c75561b5b054ad.json`，本轮已核对其内容摘要。三周期Brier改善区间均跨零，没有据此声称优于简单基准的依据。它评价历史配方回放，不等于在线重新拟合模型已被验证；选定股票集合、复权版本、历史成员和实际成交的限制仍在。

项目已有日期多折、H+1标签隔离、训练内标准化、独立校准、移动日期区块区间、执行资格和前瞻收据，本轮复用这些能力。新的代码反例包括：

1. **当前/历史量价公式错配。** 每日收盘跌1%但K实体收阳，当前v2为45，历史旧代理同日为92，造成错误分位和相似样本匹配。
2. **方向抬高证据充分度。** 同样质量、同一个亏损样本，分数越看多，充分度越高；没有因子也能非零。注明“非统计”仍不能消除语义错误。
3. **解释事后挑最佳场景。** 历史弱趋势亏损、强趋势盈利时，总引用最高收益桶，却没有确认当前属于该场景。
4. **汇总指标掩盖选股无效。** 混合牛熊日的AUC较高，不保证同一天能排对股票；全池校准不保证实际高概率子集同样可靠。
5. **除权事件污染标签。** 可通过旧元数据准入的2拆1合成样本曾被记为约−50%收益。入场后的公司行动重基无法核实，必须拒绝整个收益窗口，不能用错误标签反过来修评分。

| 原始来源 | 阅读与可采用内容 | 本地取舍 |

| [False (and Missed) Discoveries in Financial Economics，2020](https://arxiv.org/pdf/2006.04269) | 双重bootstrap与策略实验，保留横截面依赖 | 误报/漏报取决于效应假设，不存在通用阈值。记录全部尝试，按相同日期成对比较，不只保留胜者 |

严格单调校准保留排序，非严格保序还可能增加并列；校准不能凭空补足缺失的预测信息。行业和市场特征需要预测时可得的历史序列，不能把今日行业归属回填过去。

## 4. 详细修改方案

### P0：本轮直接实施

| 修改 | 代码与行为 | 验收 |
| --- | --- | --- |
| 当前/历史同公式 | 共享price_volume_scoring.py；分别准入后调用v2；历史固定6行窗口，删除K实体累计代理；因子与校准携带同一版本 | 同证据同分、开盘实体不改变收盘方向、未来后缀无影响；缺量/PIT/可比价格证据拒绝 |
| 收益标签价格基准 | 因子历史D+1开盘至D+5/D+10收盘窗口完整校验；持有期公司行动或不可比口径拒绝整个样本与分桶 | 2拆1不再伪造约−50%收益；中间缺日/无效行不跳过，合法停牌保留固定会话计数 |
| 充分度与方向分离 | 取数据质量、历史校准覆盖、固定因子份额的样本支持度三者最小值；每因子样本支持为min(样本数/30,1)，缺失为0且不转移份额，盈亏和方向不加分 | 多空对称、零样本0、单样本不足、缺项降低覆盖；公开分解与版本，旧报告不冒充v2 |
| 停止择优解释 | 固定场景顺序并列展示历史桶，明确未确认当前场景且场景可能重叠 | 交换收益不能改变场景顺序，正负历史均保留 |
| 加强预测诊断 | 新独立纯诊断模块接入方向验证v2；同日AUC、日期等权proper scores、多冻结基准成对改善、固定0.6/0.7子集 | 牛熊日反例；复制某天股票不改变日期权重；赢常数但输强基准可见；缺日不压缩区块；不自动选模/晋级 |
| 实际离线复验 | 使用已有Choice静态历史，输出独立新目录，全部周期与原窗口保留 | 不调用付费API，不覆盖数据或在线模型；披露已见窗口，核对预测值/配方保持 |

### P1：具备数据条件后推进模型迭代

1. **冻结目标与记录。** D+5方向与H5扣费盈利作为两个独立研究目标，D+1/D+2并列诊断。保存信号截止、入场代理、退出会话、特征版本、费用和股票池身份，复用前瞻收据；标签未成熟不更新模型，不能按本轮测试成绩临时换主目标。
2. **补齐大盘/行业历史。** 保存当时有效成员、指数/行业事件及获取时间、调整口径；候选特征为1/5/20日市场收益、波动率、行业相对市场和股票相对行业。足够历史窗才估滚动beta残差，并区别于简单涨幅差。没有历史归属则该层缺失；60只股票等权收益不能冒称官方指数。
3. **固定小型候选集合。** 现行规则、常数、已有经验贝叶斯分箱、正则化线性模型先比较；登记“原11特征”“加市场”“加行业”“完整上下文”消融，再研究树模型。候选、正则强度、窗口、停止规则和尝试次数在测试前冻结，参数只用训练/验证选。
4. **分离选模、校准和测试。** 日期顺序为训练、验证、校准、最终测试，按真实标签结束清除重叠。验证选候选后才在独立校准期拟合映射；测试只评价冻结方案，不反复挑周期、阈值或种子。当前40日校准不足以保证复杂校准，先比较低复杂度方案。
5. **同时评价全池与选择集合。** 冻结TOP/概率阈值集合，报告覆盖、基准命中、Brier/log loss、同日AUC、按日RankIC及市场状态。缺标签/未成交单列；和常数及经验贝叶斯在同样本比较。区块覆盖重叠跨度，并做更长区块敏感性；同日股票不是独立日期。
6. **用账户路径判断经济价值。** 复用共享资金、持仓估值、费用、整手、涨跌停、停牌和容量规则，报告日频NAV及换手。高概率不直接等于大仓位；执行资格和损失范围可解释后才研究预算映射。
7. **未来前瞻证据决定上线。** 记录全部失败和候选，保留足够未参与选择的后续日期及不同状态。晋级依据预登记的强基准改善、选择集合质量、覆盖和执行结果，不以单次命中率超过50%晋级。未达门槛保持研究状态，不设置无法保证的准确率承诺。

### P2：需新统计/授权合同解决的已知问题

- 通用概率研究的maximum_drawdown来自重叠持有期超额收益链，不能代表实际资金NAV回撤；持续绝对亏损但略跑赢基准仍可显示0。新研究版本须分别命名，缺账户轨迹时实际NAV回撤不可用，不能静默改旧产物公式。
- 2026-10-04核对现有消费者：概率面板与详情没有展示上述`outcome_metrics.maximum_drawdown`；`evaluate_market_scan_probability.py`只输出机器可读研究摘要及产物，没有该数值的HTML展示。未来如展示旧字段，应标为“超额收益序列回撤”，并说明“实际账户净值回撤未知：缺少连续账户路径”。本次仅补充语义说明，不修改既有JSON、算式、门槛、版本或摘要。策略实验室的同名字段来自独立的`session_maximum_drawdown`合同，不套用此标签。
- 候选显著性仍有独立日期符号检验假设，不能自动用于H+1重叠标签。新合同须登记依赖结构、候选集合及搜索调整；本轮不以另一未经验证的p值替代旧版检验，已有其他正式资格门禁保持。
- 经验贝叶斯基线虽被计算，部分资格路径只比较常数。新合同须要求同样本、同日期的强基准成对改善，防止赢常数却输既有简单规则的候选晋级。

本轮诊断不等于这些旧统计合同已修复，也不证明已获得正式交易优势。
