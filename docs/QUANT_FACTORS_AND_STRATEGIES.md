# 量化因子与策略

盘点及本轮修订：2026-09-19。本文件区分当前评分、冻结研究特征、策略草案和统计有效性；可编译不代表已验证收益。操作入口是“全市场选股 → 策略实验室 → 策略模板”，载入后先编译，保存、执行均由用户另外操作。

## 1. 当前因子

| 范围 | 内容 | 作用与边界 |
| --- | --- | --- |
| 个股方向分 | 趋势动量、筹码位置、量价确认、量价连续性、估值锚 | 前四项固定各1/6，估值1/3；缺失预算不转移。量价连续性是价格和成交量代理，不是真实主力资金流 |
| 个股风险与复合观察 | 风险压力、龙头强度 | 风险只扣分；龙头是复合观察，不再叠加个股总分 |
| 全市场正式排名 | 趋势、连续趋势精修、数据质量惩罚 | 当前生产画像为 `full-market-trend-only-v1`；没有另外叠加一套涨幅、量比、成交额龙头奖励 |
| 全市场研究维度 | 1/5/20日方向、置信度、风险、可交易性 | 六个研究维度，均不等同校准后的上涨概率 |
| 冻结原始特征 | 1/5/20/60日收益、跳过5日的20/55日收益、MA20斜率、均线排列、ATR20、下行波动、60日回撤、20日区间位置、量比、量价生命周期、成交额、换手率 | 共16项，保存在扫描证据中，复算后才能用于新增策略筛选 |
| 正式快照概率研究 | 原始特征、评分分解、市场/行业/板块强度和类别、交易状态等 | 注册79个模型字段，另有模型及样本准入；不因增加策略模板而重训或晋级 |
| 公共日K离线研究 | ATR14、区间位置、收益、均线偏离、回撤、振幅、波动及量比 | 11项OHLCV特征；历史版本和当时可得性限制仍适用 |

主要实现见 `research_factor_scoring.py`、`research_factor_aggregation.py`、`market_scan_score_dimensions.py`、`market_scan_probability.py`。目前个股同公式历史校准只实现量价确认与量价连续性；趋势、筹码、估值、风险及复合龙头不能用不等价的历史代理生成胜率或百分位。固定预算和传播规则见[评分第三版](SCORING_V3.md)。

## 2. 本轮可用策略

目录共15项：8个可载入草案、2个影子研究方向、5个缺少字段的方向。现有六个可载入模板的条件与权重保留；中期动量路线现在可载入，并新增低波趋势。

| 可载入策略 | 主要条件与目标 |
| --- | --- |
| 多周期均衡 | 综合1/5/20日序数分及风险、可交易性 |
| 次日延续 | 短周期延续，限制当日过热和流动性 |
| 有界中期趋势 | 中期趋势为正，限制涨幅和风险 |
| 回撤后延续 | 中期背景较强时观察有界单日回撤 |
| 防御流动性 | 风险、成交容量及中期稳定性 |
| 容量优先 | 先限制成交额和可交易性，再观察短中周期 |
| 跳过近期5日动量（本轮） | 跳过最近5日的20日收益0–25%、55日收益≥0；最近5日收益−8%至10%；60日回撤≤20%，另有风险、流动性约束 |
| 低波趋势（本轮） | 跳过5日的20日动量≥0、60日收益≥0；ATR20≤4%、20日下行半偏差≤2%、60日回撤≤15%，另有流动性约束 |

短期反转、行业相对强度仍为影子路线。价值/GARP、质量成长、红利低波、事件与预期修正、拥挤与容量仍缺少必要历史时点字段。不能用最新财报填充过去，也不能将低波趋势标为红利策略。个股页面另有趋势回踩、突破确认、支撑低吸、做T区间、风险止损五张研究策略卡，与全市场组合草案分开。

新增筛选白名单：

| 字段 | 周期 | 单位与方向 |
| --- | --- | --- |
| `skip5_return_pct` | 20、55 | 百分点，跳过最近5个交易日后计算相应窗口收益 |
| `atr_pct` | 20 | 百分点，ATR相对快照价格的比例（official为收盘价，intraday为快照报价） |
| `downside_volatility_pct` | 20 | 百分点，相对零目标的日收益下行均方根；非下跌日计零，不年化 |
| `max_drawdown_pct` | 60 | 百分点，60个收盘价的最大回撤损失幅度，正数且越小越好 |

白名单现在24项。新增项复用已冻结的原始特征，不增加生产评分权重。原始特征筛选（包括原有 `return_pct`）必须通过历史时点回放且外层值与证据负载完整一致；即使关闭一般PIT策略开关，也不能绕过此检查。缺失、篡改、不兼容的旧下行波动口径和非有限数字均拒绝。准入版本进入执行指纹，防止旧执行结果被当作新计算复用。

两个新策略默认计划持有和调仓间隔均10个交易日。编辑器分别保存这两个字段，修改持有期或其他组合参数不会覆盖原调仓间隔。这是草案声明；当前单次执行、定时运行和纸面委托不等于完整的连续组合净值回测。所有阈值均为尚未验证的研究默认值。

已增加[固定策略模板对照报告](STRATEGY_TEMPLATE_TRACKING.md)：以有界中期趋势为基线，将两个新模板应用于同一份冻结扫描，先固定选择再读取未来价格。报告分别展示D至D+H的毛收益、严格官方执行证据支持的D+1开盘至D+H+1收盘独立批次净收益，以及同合同固定非重叠日期的三模板统计比较。净收益包含基础与压力成本、整手和容量约束；缺失执行或退出受阻使整篮不可用，不补位、不重新归一。平均领先、统计优势及采用资格分开显示；当前全部是回溯比较，采用资格为空，不覆盖用户策略。命令、来源要求及检验限制见该报告文档。

## 3. 修复的计算与状态问题

- **公司行动污染历史因子**：拆股100→50的旧样本可被误算为量价10分并进入校准。`factor-volume-confirmation.v3`统一当前/历史20日窗口：精确连续可信会话、正成交量、前复权、明确交易且无公司行动；缺失或未知状态不猜测可比性，历史另须通过PIT校验。没有用更早日期填补坏行。正常准入样本的分数公式保留。
- **极低量比引发分析异常**：正成交量计算的量比可能舍入为0，共享入口将其作为不可用输入，当前因子不计分、历史不生成样本。
- **定时策略周末误报过期**：本轮将自动化当前时刻的过期提醒对齐最新执行准入的交易会话口径；official以最近已完成日K为参考，intraday以当前报价会话为参考，覆盖节假日及15:15发布边界，事件保存参考日期和会话年龄。组合草案内部仍按冻结as_of与data_date的自然日差判断历史时效，本轮未修改该冻结语义。
- **持仓权重NaN穿透**：当前权重必须是有限的0–1数字，同时满足总预算；不让NaN绕过大小比较。
- **静态目录冒充实时证据**：目录v2删去硬编码的“2个正式会话”和旧评分版本；显示模板修订日、当前源合同、有效性未评估。每次执行仍核验所选扫描的实际证据。
- **编辑草案覆盖调仓间隔**：此前持有10日、每5日调仓的草案在任意编辑后会变成10/10。新增独立调仓间隔控件并校验整数交易日；载入原值保留，缺失或无效间隔禁止编译，后台实际定时频率不随此字段改变。

较严格准入可能使部分旧扫描或来源未知的个股因子显示不可用；这是证据不足的结果。旧报告和冻结扫描不回写。

## 4. 研究依据与判断

[French动量构造说明](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/det_mom_factor_daily.html)采用此前2–12月收益，区别于最近月反转。本轮借鉴分离较早趋势与近期价格变化的思路，但20/55日且跳过5日是自定义短窗口，不是经典12–2月动量复现，更不能继承原研究的收益结论。

[Frazzini与Pedersen的Betting Against Beta](https://www.aqr.com/insights/research/journal-article/betting-against-beta)讨论杠杆约束和低beta投资；[Low-Risk Investing Without Industry Bets](https://www.aqr.com/Insights/Research/Journal-Article/Low-Risk-Investing-Without-Industry-Bets)区分行业内外的低风险效应。本项目没有用ATR冒充beta，也没有实现BAB的多空和杠杆构造。此次只把可复算的价格风险用于限制候选；未来评估还需控制行业集中、成本和成交约束。

当前优先修复输入可比性、时点证据和解释失真，再验证新增条件的信息价值。简单增加因子数或提高回测最好的一组权重都不足以支持“预测更准”。

## 5. 下一步的可执行顺序

1. **概率模型的训练折内特征去重**：当前部分评分特征是结构别名或常量。相同信号复制成多列会摊薄独立L2惩罚，改变概率。只用训练折识别精确常量、重复/相反标准化列，保存选择合同，升级模型与产物验证器；验证复制列不改变预测、验证集不能影响选择、旧产物仍按原身份读取。不得用全样本相关性预先筛选。
2. **连续研究组合状态**：明确“研究参考权重”和实际模拟账户持仓的区别，给定时草案绑定显式前序与参考权重，验证持有阈值、换手和成本连续性。目前定时执行没有自动传入 `current_weights`，重复执行可能仍估计接近整仓买入；不能把前次未成交草案当作实际持仓。
3. **预先登记前瞻比较**：固定现有基线与两个新增策略、周期、阈值和成本。已有[策略模板对照工具](STRATEGY_TEMPLATE_TRACKING.md)提供毛收益、独立批次净执行、成本压力、批次回撤和Holm校正后的三对比较；当前本地输入尚不能形成合格优胜证据。下一步应预先冻结研究计划、保存完整原始扫描和正式执行材料、积累独立前瞻日期，并在连续账户中验证换手、持仓和资金延续。不将独立批次收益连乘为真实净值，也不把回溯报告改名为样本外验证。[评分跟踪工具](SCORE_TRACKING.md)另评估排名分组的后续表现，不能替代完整策略净值。
4. **补齐历史时点基本面与行业基准**：先保存公告可得时间、当时行业归属、复权版本和交易日覆盖，再实现价值、质量、红利与行业相对强度。缺少这些证据前保留不可用状态。
