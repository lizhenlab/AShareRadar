# 固定策略模板的净收益与后续表现对照

此工具把三个固定研究模板应用于同一批冻结全市场扫描，分别展示历史毛收益、带执行约束的独立批次净收益，以及同评分合同内的选择诊断。它能检查“哪套模板在这组历史条件下更好”，不能证明未来收益更高。当前所有结果均为回溯研究，`adoptable_template_id`始终为`null`，保留用户当前策略，不自动切换、保存或覆盖草案。

| 模板标识 | 角色与内容 |
| --- | --- |
| `bounded_medium_trend` | 基线：有界中期趋势 |
| `medium_momentum` | 候选：跳过近期5日的动量，另有涨幅、回撤与流动性约束 |
| `low_volatility_trend` | 候选：正趋势下限制ATR、下行波动与回撤 |

三个模板的完整规格、模板版本和策略指纹随报告保存，不根据后续收益调整阈值、股票或权重。因子单位和策略条件见[量化因子与策略](QUANT_FACTORS_AND_STRATEGIES.md)。

从未来日期开始积累样本请使用[三策略前瞻采集](STRATEGY_PROSPECTIVE_COLLECTION.md)。该流程先冻结日历、模板与源码，再按时归档完整扫描；本页的回溯对照不能代替它，也不能把已有历史报告补登记为前瞻。

## 使用

在项目根目录执行：

```bash
.venv/bin/python tools/track_strategy_templates.py \
  --database data/ashare_radar.sqlite3 \
  --output-directory data/research/strategy_template_tracking \
  --non-overlapping-signals
```

默认观察期限`H=10`个交易日、名义资金100万元。上例在读取后续日线前，按每个评分合同的首个信号日固定每`H+1`个交易日的扫描锚点，减少重复读取；不按已成功日期重新排间隔。省略`--non-overlapping-signals`会保留每天的诊断批次，但选择统计仍独立按完整交易日历核验同一锚点规则。

命令输出JSON，包含`json_path`、`html_path`、`evidence_status`、`selection_status`及`adoptable_template_id`。前一个状态描述毛收益资料，后一个描述净收益选择证据，两者不可互换。打开HTML路径即可查看独立报告，无需启动服务或连接网络。未提供官方执行证据时仍可生成缺口报告，不能凭普通日线获得合格的净收益选择结论。

| 参数 | 行为 |
| --- | --- |
| `--database` | 必填，本地已有SQLite数据库；数据库不存在时失败，不新建数据库 |
| `--output-directory` | 必填，JSON及独立HTML的本地输出目录 |
| `--horizon` | `1`、`5`、`10`、`20`之一，默认`10`；改变报告观察期限，不改模板持有和调仓计划 |
| `--notional-cash-cny` | 默认`1000000`，范围1万元至10亿元且精确到分；每批次独立资金预算 |
| `--as-of` | 观察截止，默认当前时刻；ISO日期时间，无时区按上海时间，不能晚于当前时刻 |
| `--run-id` | 可重复；先确定同日期/合同的全局最早批次，再与请求ID相交，不能用后来重扫替代 |
| `--non-overlapping-signals` | 在收益读取前，按各合同首日及可信交易日历每`H+1`日固定扫描锚点；与`--run-id`互斥 |
| `--official-registry` | 官方执行来源注册表路径；须与下列三个参数一起提供 |
| `--official-registry-digest` | 独立确认的注册表SHA-256摘要，不把待检文件自己计算的摘要视为来源证明 |
| `--official-raw-root` | 注册表所登记的许可原始交付文件目录 |
| `--official-session-directory` | 已封存、可被严格加载器复验的逐交易日执行证据目录 |

官方参数四件套要么全部省略，要么全部提供。部分提供、核验失败或未找到有效执行会话会使命令失败，不降级成已验证的官方证据。严格加载器核验固定注册表、许可与交付身份、原始字节、会话内容及文件名摘要；普通行情缓存、手填JSON或合成夹具不能代替它们。准备材料的既有入口为`tools/ingest_market_scan_official_execution.py`，见[研究工具](RESEARCH.md)。以下路径和摘要占位符必须换成已独立核验的真实材料：

```bash
.venv/bin/python tools/track_strategy_templates.py \
  --database data/ashare_radar.sqlite3 \
  --output-directory data/research/strategy_template_tracking \
  --horizon 10 \
  --non-overlapping-signals \
  --official-registry '<来源注册表.json>' \
  --official-registry-digest '<独立确认的64位SHA-256>' \
  --official-raw-root '<许可原始交付目录>' \
  --official-session-directory '<已封存执行会话目录>'
```

指定`--run-id`时，仅请求后来的重扫既不会自动换成最早批次，也不会保留该重扫；若要纳入该日，须包含最早批次ID。选择日期或截止时刻本身属于研究范围选择，不据此获得事前登记资格。每次最多接受200个日期/评分合同，扫描头查询上限10000条；超限失败，不静默截断。固定非重叠模式先确定锚点再应用200批次限制，未落在锚点的批次记为`non_overlapping_signal_schedule`。

输出为`strategy-template-tracking-<内容摘要>.json`及同名`.html`。相同内容复用文件，已有报告不原地改写；不同截止或数据可生成新文件。报告保存在被Git忽略的本地研究目录。成功生成但证据不足时仍返回报告；输入、数据库或输出失败返回非零退出码及脱敏错误类型。HTML显示可理解的缺口原因，技术细节保留在JSON。

## 共同的数据与选择准入

1. **只读一份数据库快照。** 使用只读连接、`query_only`和单个读事务；不调用提供者、不补日线、不自动刷新日历、不训练模型、不写策略版本、执行记录或生产排名。唯一新写入是指定目录中的报告文件。
2. **先固定全局最早批次。** 仅考虑`official`全市场且完成状态为`success`或`degraded`的扫描。同信号日、规则版本和生产评分指纹取截止前最早发布的批次；同日重扫不增加样本。首批失效列为失败，不用后来批次替换。不同评分合同分别统计，不合并或跨合同挑选赢家。
3. **校验原始封存和PIT证据。** 要求冻结全市场成员完整，评分合同已注册，原始发布封印可复验。决策不早于信号日收盘，发布与封印早于次日开盘，封印不晚于报告截止。历史补封不能替代原始封印。成功候选的PIT证据须能复算，绑定股票、行情日期、模式及决策时刻，外层原始因子与证据负载一致。
4. **选股只使用冻结输入。** 三模板复用固定规格与组合约束生成独立草案，再关联后续结果；不载入实际账户持仓，也不将上一草案当作已成交持仓。未来价格缺失不会改变股票、权重或规格身份。
5. **会话和观察截止一致。** 可信交易日历及上海时间15:15日线发布截点决定最近完成会话；盘中、周末与节假日不会提前取得未成熟标签。净执行的产物生成、交付可得、取得及逐行观察时间也不得晚于报告截止。

毛收益读取本地前复权日线，另检查信号日至`D+H`完整路径、信号重叠价格、统一数据版本及日线合同，路径公司行动状态须明确为`none`。日线观察与抓取时刻均须符合截止。净执行只读取严格官方加载器提供的未复权执行行，不能用毛收益标签或前复权价格替代。可覆盖的日线缓存不是不可变历史版本；截止校验也不能将回溯重跑变为前瞻留档。

## 三种结果分层

报告总格式为`strategy-template-tracking-v2`。旧版没有以下新对象时，HTML显示“未生成净收益选择结论”，不将缺失字段解释成零收益或新证据。

| 对象 | 时间与含义 | 状态边界 |
| --- | --- | --- |
| 根节点`cohorts` | 冻结信号价格至`D+H`收盘的固定权重毛收益 | 根节点`status`、`costs_deducted=false`和`statistical_validation=not_performed`描述此层 |
| `net_comparison` | `strategy-template-net-returns-v1`；`D+1`开盘至`D+H+1`收盘的独立批次净执行情景 | 每篮及每成本情景为`available/pending/unavailable/blocked`，不生成连续账户净值 |
| `strategy_selection` | `strategy-template-selection-v1`；同合同、预固定非重叠锚点上的三模板净收益比较 | `historical_evidence_available`仅表示统计输入准入，不保证存在赢家；采用资格始终为空 |

JSON收益单位为小数比例，例如`0.02`表示2%；HTML收益显示百分比、差值显示百分点。缺失收益为`null`，不是零。

### 历史毛收益：D → D+H

```text
单股毛收益 = 固定D+H收盘价 / 冻结信号价格 - 1
组合诊断毛收益 = Σ（冻结目标权重 × 单股毛收益）
```

未配置权重按零现金收益处理，不将已投资部分归一到100%。这一层的剩余现金和往返成本是信号价格下的草案估算，成本没有从毛收益扣除，不能拼接为账户净值。

任一入选股票结果缺失，整篮记为`missing`且收益为空；已知单股仅作明细。未成熟为`pending`，日历缺失为`calendar_unavailable`，空篮为`no_selection`，不进入毛收益配对。两个候选分别与基线按同合同、同日、同期限及完整篮子配对，每个日期等权；两组可用日期不同，基线均值也可能不同。重叠股票数量不代表独立样本数。

### 净执行情景：D+1 → D+H+1

冻结目标权重变为每只股票的现金预算，预算包含买入费用，并向下取整到分。每个批次从同一名义资金重新开始，未分配和未成交资金保持现金且不计利息。按官方未复权次日开盘价、交易数量规则和前一交易日成交额容量重新计算可买股数，不复用信号价格下的股数；固定退出日按官方收盘价、卖出规则和滞后容量验证。

数值计算也须可复验：若极小价格导致股数超过可精确表示的上限`2^53-1`，该批次净收益不可用，不用舍入误差生成虚假的精确结果；上限随净执行合同记录为`maximum_exact_quantity`。

入场明确受限或资金/容量不足最低买入数量时，预算留在现金，不买替代股票。缺失执行证据、未知持有路径、公司行动需要额外账本、固定退出无法执行等，均使整篮净收益不可用，不删除失败持仓或改退出日期。尚未成熟为`pending`；来源草案阻断为`blocked`。明确的`no_trade`空篮在观察期成熟后可记录为可用现金情景、净收益0；这不等于毛收益空篮可配对，也不绕过选择层的官方来源要求。

```text
单股净损益 = 卖出金额 - 卖出费用 - 买入金额 - 买入费用
批次净收益 = Σ单股净损益 / 批次初始名义资金
批次期末现金 = 初始名义资金 + Σ单股净损益
```

`residual_cash_cny`在净执行层表示退出后的批次期末现金，不是仅指未买入资金。费用包括冻结模板指定的佣金、最低佣金、卖出印花税、过户费及双边滑点成本。基础情景使用模板完整成本；压力情景把佣金率和最低佣金各乘1.5，买卖滑点各增加10bp，税费和过户费不变。压力情景在同一冻结预算下重新计算股数，不只从原收益减去一个常数。

每批次最大回撤按初始资金与持有期间逐日收盘估值计算，最终退出扣费用；不是日内最大回撤或连续账户NAV回撤。选择层的最差批次回撤取基础和压力情景共同最差值。官方日频执行状态支持此模拟规则，不能证明订单簿排队成交。批次资金相互独立，收益不能连乘为真实账户净值，也未实现连续持仓、复投或自动调仓。

## “哪套策略更好”的判定

每个评分合同以首个信号日为起点，在完整可信交易日历上每`H+1`个会话固定锚点，覆盖该合同的首末信号日范围；失败批次日期也参与确定日历范围。统计重新核对每个锚点的`D+1`和`D+H+1`，不把成功日期压缩后再抽样。一个已经成熟的锚点缺扫描、缺任一模板、缺基础或压力结果，就阻断整个合同的推断，不用邻近日期补位。

至少20个完整锚点、官方来源、完整日历和全部成熟锚点通过后，执行双侧、零假设中心化的循环移动块bootstrap：2000次重采样，每块2个锚点，三模板使用同步日期抽样。三组两两比较全部进入Holm多重校正，家族显著性水平0.05；随机种子绑定合同、日历、成本和执行证据身份，可复验相同输入。

| 展示层 | 判定 | 不能推导的结论 |
| --- | --- | --- |
| 诊断领先 | 在没有成熟锚点缺失及来源/日历阻断时，基础净收益均值严格最高；可少于20个锚点 | 不能视为统计显著或未来胜出 |
| 统计优势 | 达到准入门槛，对另外两模板的配对均值差均为正，且各自Holm校正双侧p值严格小于0.05 | 不保证绝对盈利，也不授予采用资格 |
| 压力与风险通过 | 统计赢家在压力成本下对两者的均值差仍为正；最差独立批次回撤相较任一对手不恶化超过2个百分点 | 不是连续账户风险验证 |
| 可采用模板 | 本回溯报告始终为`null`，`promotion_eligible=false` | 不覆盖用户策略、改变生产评分或启动真实交易 |

20个锚点、2锚点块长、2000次重采样、2个百分点风险容差及成本压力幅度均是本项目的工程研究合同，不是论文保证或充分检验功效证明。非重叠窗口仍可能存在长期依赖和市场制度变化；固定短块bootstrap与Holm也不能修复无效单项p值、错误成交模型、看过结果后的改规则或反复查看。同一固定三模板家族的校正不覆盖跨合同、改模板、改期限和改日期范围的额外探索。

## 方法依据与当前取舍

以下原始资料核对于2026-09-19。论文用于约束解释和研究设计，不是本项目策略获利的证据。

| 原始来源 | 采用的原则与限制 |
| --- | --- |
| [Bailey、Borwein、López de Prado、Zhu，The Probability of Backtest Overfitting，2015作者稿](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf) | 事后挑选回测赢家会产生选择偏差；应保存完整试验族。当前未运行CSCV，也不输出PBO数字；净收益领先不代替独立前瞻验证。 |
| [Harvey、Liu、Zhu，… and the Cross-Section of Expected Returns，RFS 2016](https://people.duke.edu/~charvey/Research/Published_Papers/P118_and_the_cross.PDF) | 明确完整比较族及多重检验目标，不只报告最好的单项p值。不直接照搬因子文献的t统计阈值，也不认为三对校正覆盖了未知历史探索。 |
| [Holm，A Simple Sequentially Rejective Multiple Test Procedure，1979](https://www.jstor.org/stable/4615733) | 对三对预定比较使用逐步Holm校正控制家族错误率；保证依赖输入p值有效，不能替代时间依赖建模和来源准入。 |

独立判断是先把可复验执行与缺失规则做好，再观察候选是否仍有优势。此处只增加回溯诊断，不因为多一个统计步骤就提高采用资格。前瞻采集入口已支持在结果产生前冻结模板、比较族、日期、成本与源码，并保留原始输入和缺失；后续仍需独立时间戳证据、连续资金/持仓验证及完整前瞻统计评估。
