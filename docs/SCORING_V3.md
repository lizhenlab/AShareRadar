# 个股评分第三版：固定预算与证据传播

日期：2026-09-15。迭代对象为个股研究因子总分及其下游解释，不替换冻结的全市场概率模型。前一轮的预测目标、历史诊断和未来模型条件见[评分预测修改方案](PREDICTION_IMPROVEMENT_PLAN.md)。

## 1. 问题与可复现反例

- 旧聚合将剩余因子重新归一：趋势80、量价20原为53，量价不可用后变80。缺失不能扩大剩余正向证据的预算。
- 其余方向因子全50时，低风险及质量奖励仍使总分54–56；低风险不能单独证明会上涨。
- 相同因子数值，仅换手7.99变8.00，画像切换使总分62变67，形成没有新增方向证据的跳变。
- 量比1时涨跌±2%都曾得到56；缩量比0.69时涨幅1.99为52、涨幅2.00反而44。旧公式将量能充足与上涨混淆。
- 已排除的复合龙头、不可用因子、低风险仍可经Alpha证据入口重新加看多；未准入历史也能加权解释。
- 多周期本身61分时，因子总分跨60额外加4，直接变成65分共振；诊断又叠加一次已经进入Alpha的环境修正，并可能突破已有充分度上限。
- 实时趋势含换手率且量比精度与历史代理不同，存在当前63/历史55、当前64/历史58的同日反例；不能拿这个历史代理给实时分生成胜率或百分位。

## 2. v3计算与版本

新报告携带 `score_aggregation.version=factor-aggregation.v3`，旧报告该字段为空，不回写旧历史。

| 证据组 | 总预算 | 固定槽位 |
| --- | ---: | --- |
| 趋势与价位 | 1/3 | 趋势动量1/6、筹码/价位1/6 |
| 量价 | 1/3 | 5/20日量能确认1/6、当日/前5日量价热度1/6 |
| 估值 | 1/3 | 估值锚1/3 |

方向分 = 50 + Σ固定份额×(已准入因子分−50)。缺失槽位贡献为0，预算不转移；因此丢失负证据可回归中性，但不能把另一因子放大到全部预算。相同股票风格下和跨画像均使用同一预算。

风险扣分 = max(0,50−风险压力分)×0.25；缺失风险不生成虚构扣分，低风险不生成正奖励。风险观察仍含质量及已有风险信息，因此单列风险扣分，不将它称为纯价格风险。最终总分在减去风险后截到0–100并仅取整一次。使用整数预算单位，防止浮点误差使7.5错误取成7。

重复已知ID拒绝，未知ID不占份额，复合项仅展示。输出组贡献、实际覆盖、固定份额和排除项；当前方向和历史证据仍分别披露。固定组预算用于约束同源信息的最大影响，不代表组间已被统计去相关，更不代表最优收益权重。

量能确认公式：50 + clip(5×收益百分点,−40,40)×clip(5/20日量比,0.5,1.25)，最后取整。平价50，多空对称，缩量减弱方向幅度；当前和历史调用同一函数。2026-09-15发布为 `factor-volume-confirmation.v2`；2026-09-19将当前与历史窗口准入统一后升为 `factor-volume-confirmation.v3`，正常样本公式不变。此函数的斜率、范围和组预算都是工程参数，尚未完成收益预测校准。

## 3. 输入与传播约束

- 量能仅在official模式、明确收盘时间、行情与最新日K同日同价、昨收一致时参与。最新20根必须精确覆盖可信日历中的全部交易日；即使上游已删除坏行，也不能用更早行补位。用日K重算收益和5/20比；盘中、盘前、错日、缺失不允许把旧量窗和新涨幅混合。
- 2026-09-19补充：当前与历史都要求这20日正成交量、统一前复权、明确交易且无公司行动，未知状态不能推断为无事件；量比舍入为0时不可用。历史校准额外保留PIT要求，拆股和日期缺口不生成低分或中性校准样本。详见[量化因子与策略](QUANT_FACTORS_AND_STRATEGIES.md)。
- 实时趋势分保留，版本为 `factor-current-trend.v1`；由于日K不能还原当前换手与信息截止，历史校准、分桶和百分位同时停止。恢复历史评价需另建共享的研究趋势输入合同。
- Alpha拒绝缺失、不参与、复合及已排除因子。风险最多提供负影响；历史影响及胜率解释需要可用、允许聚合、明确相同版本，旧版本不明不能当作新版证据。读取旧报告也要验证注册ID、明确用途和身份唯一，不能绕过当前生成器。
- 多周期共振只由各周期自身计算，删除因子总分加成；诊断不再次叠加市场环境，保留行动、因子充分度及风险限制。
- v3持久报告读取检查总分、份额、用途、覆盖与扣分链一致性；页面独立核对头部及因子字段，不一致时提示等待刷新。页面显示固定预算和分项计算；零值正常，缺失/非法版本不冒充v3。画像仅作描述，旧报告保留原有显示方式。

## 4. 研究判断与下一步

[The Uncertainty of Machine Learning Predictions in Asset Pricing（2025）](https://arxiv.org/html/2503.00549v1)在第2节区分预测均值和预测不确定性，讨论共同因子造成的横截面依赖，强调不能把股票数量当作同等数量的独立信息。本轮采纳的是分离方向与证据、约束重复传播的原则；论文的渐近置信区间并不适用于本项目当前启发式分数，没有把其公式改装成概率。

先修方向与传播的一致性，再通过更早登记的同日AUC、日期等权概率损失及扣费后账户结果验证新增信息。当前60股票的已见历史窗口不能再次作为独立胜者选择集。固定预算不是已拟合的最优模型，不能把修复后的分数变化称为命中率改善。市场/行业PIT历史、真实前瞻检验以及旧概率合同的回撤、依赖检验、强基准门槛问题，仍按前一轮计划推进。
